# 實踐大學資管系 學分追蹤器

追蹤畢業學分（128 學分）與兩個深化學程（雲端運算與資訊安全、人工智慧與數位媒體）
進度的單頁網頁 App。純 HTML / CSS / JavaScript，無任何框架，可直接放 GitHub Pages。

## 功能

- 依年級（大一～大四）與類別（校必／通識／院必／系必／學程／選修）分區顯示課程，勾選「已修完」
- 自動計算：已修總學分、剩餘學分、畢業進度條
- 兩個深化學程各自獨立的進度條，並列出還沒修的課
- 畢業門檻（系門檻／體適能／中文／英檢）通過狀態切換
- 勾選狀態存在瀏覽器 localStorage，重新整理不會消失
- 「匯出 / 匯入 JSON」備份與還原勾選紀錄
- 實習課程(一)~(四) 學分認列上限（最多 6 學分）自動處理

## 怎麼修改課程資料

**全部課程資料都在 [`data/courses.js`](data/courses.js)**，檔案內有詳細欄位說明。
特別注意：

1. 「人工智慧與數位媒體學程」目前是**範例占位課程**（課名有【範例請修改】字樣），
   請對照系上公告的學程科目表修改。
2. 兩個學程的結業學分 `requiredCredits` 目前先填 15，請依實際規定調整。
3. 通識六個尚未修的領域也是占位課程，請填入實際選修的課名與學分。

## 本機開啟

直接雙擊 `index.html` 即可（資料檔是 `.js` 而非 `.json`，不會被瀏覽器 CORS 擋住）。

## 部署

推送到 `main` 分支後，`.github/workflows/deploy-pages.yml` 會自動部署到 GitHub Pages。
